# Duxiang.ai

一个 Chrome/Edge 扩展工具，帮助你管理阅读内容，方便随时保存和查看你想阅读的网页链接。

第一版，它是比浏览器收藏夹更好用的收藏夹。

未来会加入更多智能功能，敬请期待。

## 功能特点

- 📌 **快速保存** - 使用快捷键快速保存当前页面到阅读列表
- 📚 **阅读列表管理** - 在弹出窗口中查看和管理所有保存的链接
- 🔍 **智能搜索** - 支持按标题、URL 或标签搜索链接
- 📌 **置顶功能** - 将重要链接置顶，方便快速访问
- ✏️ **编辑功能** - 随时编辑链接的标题、URL 和标签
- 📥 **导入收藏夹** - 一键导入浏览器收藏夹中的所有链接
- 💾 **数据导入导出** - 支持导入/导出 JSON 格式的数据备份
- 💿 **本地存储** - 使用 IndexedDB 存储，数据安全可靠

## 安装步骤

1. 下载或克隆此仓库到本地
2. 打开 Chrome 浏览器，进入扩展管理页面：
   - 在地址栏输入 `chrome://extensions/`
   - 或者点击浏览器右上角的菜单 -> 更多工具 -> 扩展程序
3. 在扩展管理页面右上角启用"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择本仓库所在的文件夹

## 使用方法

### 保存当前页面

- 按下 `Shift + Alt + S` 打开保存窗口
- 保存窗口会自动填充当前页面的标题和 URL
- 可以编辑标题、URL，并添加标签（用逗号分隔）
- 点击"保存"按钮或按 `Enter` 键保存
- 按 `ESC` 键取消并关闭窗口

> 如果快捷键无效，可以在 Chrome 的扩展程序快捷键设置页面（`chrome://extensions/shortcuts`）中自行设置快捷键

### 管理阅读列表

- 点击扩展图标打开阅读列表弹出窗口
- 在搜索框中输入关键词，实时搜索标题、URL 或标签
- 点击链接标题或 URL 在新标签页中打开链接
- 使用置顶按钮（📌）将重要链接置顶显示
- 使用编辑按钮（✏️）编辑链接信息
- 使用删除按钮（×）删除不需要的链接

### 导入和导出

- **导入收藏夹**：点击"导入收藏夹"按钮，将浏览器收藏夹中的所有链接导入到阅读列表（已存在的链接会自动跳过）
- **导入 JSON**：点击"导入 JSON"按钮，选择之前导出的 JSON 文件进行导入
- **导出数据**：点击"导出"按钮，将所有链接导出为 JSON 文件，方便备份

## 数据结构

每个链接包含以下字段：
- `title` - 链接标题
- `url` - 链接地址
- `tags` - 标签（字符串，多个标签用逗号分隔）
- `timestamp` - 保存时间戳
- `pinned` - 是否置顶（布尔值）

## 技术说明

- 使用 **IndexedDB** 进行本地数据存储，支持大量数据且性能优秀
- 支持从旧版本的 Chrome Storage 自动迁移数据
- 使用 ES6 模块化开发，代码结构清晰
- 响应式设计，界面简洁美观

## 权限说明

扩展需要以下权限：
- `activeTab` - 获取当前活动标签页信息
- `tabs` - 创建新标签页
- `storage` - 数据存储（用于数据迁移）
- `bookmarks` - 读取浏览器收藏夹（导入功能）
- `scripting` - 脚本注入
- `commands` - 快捷键支持

## 注意事项

- 确保已经启用了扩展程序
- 如果快捷键无效，可能是与其他程序冲突，可以在 Chrome 的扩展程序快捷键设置中修改
- 数据存储在本地 IndexedDB 中，清除浏览器数据可能会丢失已保存的链接，建议定期导出备份
