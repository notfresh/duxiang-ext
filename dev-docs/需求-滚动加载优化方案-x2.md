# 渐进式加载 - 实现记录

## 一、方案回顾

根据 `渐进式加载.md` 的设计方案：
- 首屏渲染前 100 条链接
- 后台每 200ms 追加 10 条
- 搜索策略：方案 A（只搜索已渲染数据）
- 弹窗关闭时停止后台加载

## 二、改动文件清单

| 文件 | 改动内容 |
|------|---------|
| `js/render.js` | 新增 `appendLinks()` 追加渲染函数 |
| `popup.js` | 重构 `loadLinksFromStorage()`，新增 `scheduleBackgroundLoading()`，调整搜索逻辑 |
| `popup.html` | 新增加载进度条 UI |

## 三、实施步骤

### 步骤 1：修改 render.js - 新增追加渲染函数

**目标**：新增 `appendLinks()` 函数，将链接卡片追加到容器末尾（而非清空重渲染）。

**改动**：
- 新增 `export function appendLinks(container, links, onDelete, onEdit, onPin, onLog)` 函数
- 与现有 `renderLinks` 逻辑相同，但不清空容器

### 步骤 2：修改 popup.html - 添加加载进度 UI

**目标**：在 `#linksContainer` 上方或底部添加进度提示条。

**改动**：
- 在搜索框和 linksContainer 之间添加进度条元素 `#loadingProgress`
- 添加对应 CSS 样式

### 步骤 3：修改 popup.js - 核心加载逻辑

**目标**：拆分加载流程为"首屏加载"和"后台渐进加载"。

**改动**：
- 新增渐进式加载相关状态变量
- 重构 `loadLinksFromStorage()`：只渲染前 100 条，启动后台加载
- 新增 `scheduleBackgroundLoading()` 函数
- 新增 `stopBackgroundLoading()` 中断函数
- 修改 `renderLinksList()` 支持追加模式
- 修改搜索逻辑：搜索只针对已渲染数据（方案 A）
- 监听窗口关闭事件

### 步骤 4：验证

- 检查所有文件无语法错误
- 确认现有功能不受影响（删除、编辑、置顶、归档等操作触发 `loadLinksFromStorage()` 时的行为）
