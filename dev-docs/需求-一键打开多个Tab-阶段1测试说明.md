# Tab集合功能 - 阶段1测试说明

## 功能概述

阶段1实现了Tab集合的基础功能，包括：
1. 创建Tab集合
2. 添加链接到集合
3. 一键打开集合中的所有链接
4. 基本UI界面

## 测试步骤

### 1. 测试创建集合

1. 打开扩展popup窗口
2. 点击标题栏右侧的"Tab集合"按钮
3. 点击"创建新集合"按钮
4. 输入集合名称（如"工作相关"）
5. 点击"保存"
6. **预期结果**: 集合创建成功，自动打开"添加链接到集合"对话框

### 2. 测试添加链接到集合

1. 在"添加链接到集合"对话框中
2. 可以看到所有已保存的链接列表（带复选框）
3. 勾选要添加的链接（可以多选）
4. 可以使用搜索框过滤链接
5. 可以使用"全选"复选框快速选择所有链接
6. 点击"添加"按钮
7. **预期结果**: 链接已添加到集合，对话框关闭，集合列表中显示链接数量

### 3. 测试一键打开集合

1. 在Tab集合管理对话框中
2. 找到已创建的集合
3. 点击"打开"按钮
4. **预期结果**: 
   - 浏览器中打开集合中的所有链接（每个链接一个新标签页）
   - 状态栏显示"已打开 X 个链接"
   - 对话框自动关闭

### 4. 测试编辑集合

1. 在Tab集合管理对话框中
2. 找到要编辑的集合
3. 点击"编辑"按钮
4. 修改集合名称
5. 点击"保存"
6. **预期结果**: 集合名称已更新

### 5. 测试删除集合

1. 在Tab集合管理对话框中
2. 找到要删除的集合
3. 点击"删除"按钮
4. 确认删除
5. **预期结果**: 集合已删除，从列表中移除

### 6. 测试添加链接功能（已有集合）

1. 在Tab集合管理对话框中
2. 找到已有集合
3. 点击"+链接"按钮
4. 在添加链接对话框中选择链接
5. 点击"添加"
6. **预期结果**: 链接已添加到集合，集合的链接数量更新

### 7. 测试边界情况

1. **空集合打开**: 创建一个空集合，尝试打开
   - **预期结果**: 提示"集合中没有链接"

2. **重复添加链接**: 将同一个链接多次添加到集合
   - **预期结果**: 不会重复添加（使用Set去重）

3. **空名称集合**: 尝试创建名称为空的集合
   - **预期结果**: 提示"集合名称不能为空"

4. **大量链接**: 创建包含大量链接的集合并打开
   - **预期结果**: 所有链接都能正常打开（有适当的延迟避免浏览器限制）

## 已知限制

1. 阶段1暂不支持从集合中移除单个链接（需要编辑整个集合）
2. 阶段1暂不支持集合排序
3. 阶段1暂不支持集合描述/备注

## 后续阶段计划

- **阶段2**: 完善集合管理功能（移除链接、优化UI等）
- **阶段3**: UI优化和增强功能（集合排序、描述等）
