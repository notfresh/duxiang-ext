# 代码组织方案

## 当前代码结构分析

### 现有文件
```
duxiang-ext/
├── background.js          # 后台服务，处理快捷键命令
├── popup.html             # 弹窗页面
├── popup.js               # 弹窗逻辑（294行，功能集中）
├── input.html             # 输入表单页面
├── input.js               # 输入表单逻辑
├── manifest.json          # 扩展配置
└── icons/                 # 图标资源
```

### 问题
- `popup.js` 功能集中，代码较长（294行）
- 所有功能混在一起，难以维护
- 新增功能（搜索、导入收藏夹）会让文件更臃肿

## 代码组织方案

### 方案一：模块化拆分（推荐）

#### 文件结构
```
duxiang-ext/
├── background.js
├── popup.html
├── popup.js               # 主入口，初始化
├── input.html
├── input.js
├── manifest.json
├── js/                    # 新增：JavaScript模块目录
│   ├── storage.js         # 存储操作模块
│   ├── search.js          # 搜索功能模块
│   ├── bookmarks.js       # 收藏夹导入模块
│   ├── render.js          # 渲染模块
│   └── utils.js           # 工具函数模块
└── icons/
```

#### 模块职责划分

**1. `popup.js` - 主入口（精简）**
- DOM 元素获取
- 事件绑定
- 模块协调
- 状态管理（全局状态）

**2. `js/storage.js` - 存储操作**
```javascript
// 职责：
- loadLinks()           // 加载链接
- saveLinks(links)       // 保存链接
- deleteLink(index)      // 删除链接
- addLink(link)          // 添加链接
- exportLinks()          // 导出链接
```

**3. `js/search.js` - 搜索功能**
```javascript
// 职责：
- searchLinks(keywords, links)  // 搜索链接
- filterByTitle(keyword, links)  // 按标题过滤
- filterByTags(keyword, links)   // 按标签过滤
- debounce(func, delay)          // 防抖函数
```

**4. `js/bookmarks.js` - 收藏夹导入**
```javascript
// 职责：
- importBookmarks()              // 导入收藏夹
- convertBookmarkToLink(bookmark) // 转换书签格式
- getBookmarkPath(bookmark)       // 获取书签路径
- checkDuplicate(url, links)      // 检查重复
```

**5. `js/render.js` - 渲染模块**
```javascript
// 职责：
- renderLinks(links, container)  // 渲染链接列表
- createLinkCard(link, index)     // 创建链接卡片
- showEmptyState(container)       // 显示空状态
- showSearchEmptyState(container)  // 显示搜索空状态
```

**6. `js/utils.js` - 工具函数**
```javascript
// 职责：
- showStatus(message, isError)    // 显示状态消息
- log(message)                    // 日志记录
- formatDate(timestamp)           // 格式化日期
- parseTags(tagsString)           // 解析标签字符串
```

#### 代码示例结构

**popup.js（主入口）**
```javascript
// 导入模块
import { loadLinks, saveLinks, deleteLink } from './js/storage.js';
import { searchLinks, setupSearch } from './js/search.js';
import { importBookmarks } from './js/bookmarks.js';
import { renderLinks, createLinkCard } from './js/render.js';
import { showStatus, log } from './js/utils.js';

// 全局状态
let loadedLinks = [];
let searchKeyword = '';
let isDebugMode = false;

// DOM 元素
const linksContainer = document.getElementById('linksContainer');
const searchInput = document.getElementById('searchInput');
// ...

// 初始化
document.addEventListener('DOMContentLoaded', () => {
  setupSearch(searchInput, handleSearch);
  setupEventListeners();
  loadAndRenderLinks();
});

// 事件处理
function handleSearch(keyword) {
  searchKeyword = keyword;
  const filtered = searchLinks(keyword, loadedLinks);
  renderLinks(filtered, linksContainer);
}
```

## 推荐方案：方案一（模块化拆分）

### 优势
1. **可维护性**：功能清晰，易于定位和修改
2. **可测试性**：每个模块可独立测试
3. **可扩展性**：新增功能只需添加新模块
4. **代码复用**：模块可在其他地方复用
5. **团队协作**：不同开发者可并行开发不同模块

### 实现步骤
1. 创建 `js/` 目录
2. 按模块拆分现有代码
3. 使用 ES6 模块（import/export）
4. 更新 `popup.html` 中的 script 标签（使用 type="module"）

### 注意事项
- Chrome 扩展支持 ES6 模块（Manifest V3）
- 需要在 `popup.html` 中设置 `<script type="module">`
- 保持向后兼容，确保功能正常

## 文件命名规范

- **模块文件**：小写字母，使用连字符或下划线（`storage.js`, `bookmarks.js`）
- **函数命名**：驼峰命名（`loadLinks`, `searchLinks`）
- **常量命名**：大写字母+下划线（`MAX_RESULTS`, `DEBOUNCE_DELAY`）

## 代码风格

- 使用 ES6+ 语法
- 函数注释：JSDoc 风格
- 错误处理：统一的错误处理机制
- 日志：统一的日志记录方式
