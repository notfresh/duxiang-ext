# 当前存储实现说明

## 存储技术栈

### 使用的 API
- **Chrome Storage API**: `chrome.storage.local`
- **存储类型**: 本地存储（Local Storage）
- **权限配置**: 已在 `manifest.json` 中声明 `"storage"` 权限

## 数据结构

### 存储键名
```javascript
const STORAGE_KEY = 'readingLinks';
```

### 数据格式
存储的是一个**数组**，每个元素是一个链接对象：

```javascript
{
  title: string,        // 链接标题
  url: string,          // 链接地址
  tags: string,         // 标签（逗号分隔的字符串）
  timestamp: string     // ISO 格式的时间戳
}
```

### 示例数据
```javascript
[
  {
    title: "Python教程",
    url: "https://example.com/python",
    tags: "学习,编程",
    timestamp: "2024-01-15T10:30:00.000Z"
  },
  {
    title: "项目A",
    url: "https://example.com/project-a",
    tags: "工作",
    timestamp: "2024-01-14T09:20:00.000Z"
  }
]
```

## 存储操作

### 1. 读取数据（popup.js）

```javascript
// 加载存储的链接
function loadLinks() {
  chrome.storage.local.get(['readingLinks'], function(result) {
    if (chrome.runtime.lastError) {
      // 错误处理
      return;
    }
    
    // 获取链接数组
    loadedLinks = result.readingLinks || [];
    
    // 渲染链接
    // ...
  });
}
```

**特点**：
- 使用回调函数方式（非 Promise）
- 默认值处理：`result.readingLinks || []`
- 错误处理：检查 `chrome.runtime.lastError`

### 2. 保存数据（input.js）

```javascript
// 添加新链接
const newLink = {
  title: title,
  url: url,
  tags: tags,
  timestamp: new Date().toISOString()
};

// 读取现有数据
chrome.storage.local.get(['readingLinks'], function(result) {
  let savedLinks = result.readingLinks || [];
  
  // 确保是数组
  if (!Array.isArray(savedLinks)) {
    savedLinks = [];
  }
  
  // 添加到数组开头（最新在前）
  savedLinks.unshift(newLink);
  
  // 保存更新后的数组
  chrome.storage.local.set({readingLinks: savedLinks}, function() {
    // 保存成功后的操作
  });
});
```

**特点**：
- 先读取，再修改，最后保存（完整替换）
- 新链接添加到数组开头（`unshift`）
- 数组类型检查，防止数据损坏

### 3. 删除数据（popup.js）

```javascript
// 删除链接
function deleteLink(index) {
  // 从内存数组中移除
  loadedLinks.splice(index, 1);
  
  // 保存更新后的数组
  chrome.storage.local.set({readingLinks: loadedLinks}, function() {
    if (chrome.runtime.lastError) {
      // 错误处理
      return;
    }
    // 重新加载显示
    loadLinks();
  });
}
```

**特点**：
- 直接操作内存数组，然后保存整个数组
- 删除后重新加载列表

### 4. 导出数据（popup.js）

```javascript
// 导出数据
function exportData() {
  const exportData = JSON.stringify(loadedLinks, null, 2);
  const blob = new Blob([exportData], {type: 'application/json'});
  const url = URL.createObjectURL(blob);
  
  const a = document.createElement('a');
  a.href = url;
  a.download = `reading_links_${new Date().toISOString().split('T')[0]}.json`;
  a.click();
}
```

**特点**：
- 直接从内存数组导出，不读取存储
- 导出为 JSON 文件

## 存储位置

### Chrome Storage Local
- **位置**: 浏览器本地存储
- **持久化**: 数据持久保存，即使关闭浏览器
- **限制**: 
  - 每个扩展最多 10MB
  - 单个键值对最大 8MB
- **同步**: 不同设备间**不同步**（如需同步需使用 `chrome.storage.sync`）

## 当前实现的问题

### 1. 回调地狱
- 使用回调函数，代码嵌套较深
- 可以考虑使用 Promise 包装

### 2. 数据一致性
- 删除操作直接修改内存数组，如果保存失败可能导致数据不一致
- 建议：先保存成功后再更新内存

### 3. 错误处理
- 部分操作缺少完整的错误处理
- 需要统一错误处理机制

### 4. 性能问题
- 每次操作都是完整替换整个数组
- 如果数据量大，可能影响性能

## 改进建议

### 1. 使用 Promise 包装
```javascript
// 改进后的存储操作
function loadLinks() {
  return new Promise((resolve, reject) => {
    chrome.storage.local.get(['readingLinks'], (result) => {
      if (chrome.runtime.lastError) {
        reject(chrome.runtime.lastError);
      } else {
        resolve(result.readingLinks || []);
      }
    });
  });
}
```

### 2. 统一存储模块
```javascript
// js/storage.js
const Storage = {
  async loadLinks() { ... },
  async saveLinks(links) { ... },
  async addLink(link) { ... },
  async deleteLink(index) { ... }
};
```

### 3. 数据验证
- 添加数据格式验证
- 防止存储损坏的数据

### 4. 批量操作优化
- 对于大量数据，考虑分批处理
- 添加操作队列，避免并发冲突

## 存储操作流程图

```
添加链接：
input.js → 读取现有数据 → 添加新链接 → 保存完整数组 → 关闭窗口

删除链接：
popup.js → 确认删除 → 修改内存数组 → 保存完整数组 → 重新加载

加载链接：
popup.js → 读取存储 → 渲染列表

导出数据：
popup.js → 读取内存数组 → 生成JSON → 下载文件
```
