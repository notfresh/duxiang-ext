# 标题搜索

## 改造思路

### 核心想法

在 `searchLinks` 函数中，**解析输入前先把 `tag:XXX` 片段单独提取出来**，与普通关键词分开处理，然后用 AND 逻辑组合过滤。

### 解析规则（search.js）

输入 `tag:前端 react` 拆成两部分：
- **tag 过滤器**：`tag:前端` → 只在 `link.tags` 里精确/模糊匹配 `前端`
- **普通关键词**：`react` → 继续在标题、URL、标签里全文搜索

伪代码：
```js
function parseSearchText(searchText) {
  const tagFilters = [];
  const keywords = [];

  for (const token of searchText.trim().split(/\s+/)) {
    if (token.startsWith('tag:')) {
      const tagValue = token.slice(4);   // 取冒号后面部分
      if (tagValue) tagFilters.push(tagValue.toLowerCase());
    } else if (token) {
      keywords.push(token.toLowerCase());
    }
  }
  return { tagFilters, keywords };
}
```

### 过滤逻辑（修改 `matchesAllKeywords`）

```js
function matchesLink(link, tagFilters, keywords) {
  const tags = parseTags(link.tags || '');
  
  // tag: 过滤：每个 tag filter 都必须在 tags 里找到至少一个匹配
  const tagMatch = tagFilters.every(tf =>
    tags.some(t => t.toLowerCase().includes(tf))
  );
  
  // 普通关键词：匹配标题 / URL / 任意标签
  const keywordMatch = keywords.every(kw =>
    matchesKeyword(link.title, kw) ||
    matchesKeyword(link.url, kw) ||
    tags.some(t => matchesKeyword(t, kw))
  );
  
  return tagMatch && keywordMatch;
}
```

### 示例效果

| 输入 | 行为 |
|---|---|
| `tag:前端` | 仅显示含 `前端` 标签的条目 |
| `tag:前端 react` | 含 `前端` 标签 **且** 标题/URL含 `react` |
| `tag:前端 tag:工具` | 同时含 `前端` 和 `工具` 两个标签 |
| `react` | 原有全文搜索，不变 |

### 改动范围

只需改 **search.js** 一个文件：
1. 新增 `parseSearchText()` 函数
2. 修改 `searchLinks()` 调用新解析函数
3. 替换 `matchesAllKeywords()` 为支持 tagFilters 的版本

popup.js、popup.html 均无需改动。
