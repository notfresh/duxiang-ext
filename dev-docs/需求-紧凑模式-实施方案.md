# 紧凑模式功能 - 分阶段实施方案

## 需求概述

增加一个设置功能，提供"紧凑模式"选项，通过减小行高、优化布局、隐藏可选内容等方式，让阅读列表在有限空间内显示更多链接。

## 当前UI结构分析

### 链接卡片当前布局
```
┌─────────────────────────────────────┐
│ [标题]              [📌] [✎] [×]   │  ← 头部（.card-header）
│ https://example.com/...             │  ← URL（.link-url）
│ [标签1] [标签2]      2026/01/02 22:38│  ← 元信息（.link-meta）
└─────────────────────────────────────┘
```

### 当前样式参数
- 卡片内边距：`padding: 12px`
- 卡片间距：`margin-bottom: 10px`
- 头部底部间距：`margin-bottom: 8px`
- URL底部间距：`margin-bottom: 8px`
- 标题字号：`font-size: 16px`
- URL字号：`font-size: 14px`
- 时间戳字号：`font-size: 12px`

#### 5.5 JavaScript实现

**5.5.1 设置数据结构扩展**
```javascript
{
  compactMode: {
    enabled: false,
    showUrl: true,
    showDate: true,
    showTags: true,
    titleMaxChars: 0,      // 0表示不限制
    urlMaxChars: 0         // 0表示不限制
  }
}
```

**5.5.2 文本截断函数**
```javascript
/**
 * 截断文本并添加省略号
 * @param {string} text - 原始文本
 * @param {number} maxChars - 最大字符数（0表示不限制）
 * @returns {string} 截断后的文本
 */
function truncateText(text, maxChars) {
  if (!maxChars || maxChars <= 0) {
    return text;
  }
  if (text.length <= maxChars) {
    return text;
  }
  return text.substring(0, maxChars) + '...';
}

/**
 * 应用文本截断到链接卡片
 * @param {HTMLElement} card - 链接卡片元素
 * @param {Object} settings - 设置对象
 */
function applyTextTruncation(card, settings) {
  const compactMode = settings.compactMode || {};
  const titleMaxChars = compactMode.titleMaxChars || 0;
  const urlMaxChars = compactMode.urlMaxChars || 0;
  
  // 处理标题
  const titleElement = card.querySelector('.link-title');
  if (titleElement && titleMaxChars > 0) {
    const originalTitle = titleElement.getAttribute('data-original-title') || titleElement.textContent;
    titleElement.setAttribute('data-original-title', originalTitle);
    titleElement.textContent = truncateText(originalTitle, titleMaxChars);
    titleElement.title = originalTitle; // 悬停显示完整内容
  }
  
  // 处理URL
  const urlElement = card.querySelector('.link-url a');
  if (urlElement && urlMaxChars > 0) {
    const originalUrl = urlElement.getAttribute('data-original-url') || urlElement.textContent;
    urlElement.setAttribute('data-original-url', originalUrl);
    urlElement.textContent = truncateText(originalUrl, urlMaxChars);
    urlElement.title = originalUrl; // 悬停显示完整内容
  }
}
```

**5.5.3 编辑框改造**
- 在 `popup.html` 中将标题和URL的 `<input>` 改为 `<textarea>`
- 在 `popup.js` 中更新相关的DOM获取和事件处理
- 保持标签输入框为单行（标签通常较短）

#### 5.6 实现要点

1. **文本截断**
   - 使用CSS `text-overflow: ellipsis` 实现单行截断
   - 通过JavaScript动态应用截断逻辑
   - 保存原始文本，以便悬停时显示完整内容
   - 考虑中文字符的显示宽度（中文字符通常占2个英文字符宽度）

2. **编辑框优化**
   - 使用 `<textarea>` 替代 `<input>` 支持多行输入
   - 设置合适的 `min-height` 和 `max-height`
   - 允许用户调整大小（`resize: vertical`）
   - 保持标签输入框为单行（标签用逗号分隔，通常较短）

3. **用户体验**
   - 字符数限制为0时表示不限制
   - 悬停时显示完整内容（使用 `title` 属性）
   - 编辑时显示完整内容，不受截断限制
   - 保存后应用截断规则

4. **性能考虑**
   - 文本截断在渲染时执行，避免频繁DOM操作
   - 使用CSS截断优先，JavaScript截断作为补充
   - 考虑大量链接时的性能影响

## 技术实现细节

### 存储方案
**方案A：使用 IndexedDB（推荐）**
- 优点：与现有数据存储一致，性能好
- 缺点：需要扩展存储模块

**方案B：使用 Chrome Storage**
- 优点：简单，已有权限
- 缺点：与主数据存储方式不一致

**推荐：方案A**，在 `js/storage.js` 中扩展，添加 `settings` 对象存储。

### 渲染更新策略
1. **设置变更时**：
   - 保存设置到存储
   - 更新DOM类名
   - 重新渲染链接列表（调用 `renderLinks()`）

2. **加载时**：
   - 读取设置
   - 应用类名到容器
   - 正常渲染链接

### 性能考虑
- 使用CSS类切换，避免频繁DOM操作
- 设置变更时批量更新，减少重排
- 考虑使用 `requestAnimationFrame` 优化渲染
